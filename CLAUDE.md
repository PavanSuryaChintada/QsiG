## 1. What this is

**SIH 2026 · PS 26141 · Quantum-Inspired Cyber Threat Detection for Digital Signature Security · Egreen Quanta · Theme: Blockchain & Cybersecurity**

A **live diagnostic instrument** for teleportation-based Quantum Digital Signature channels. It does not merely check whether an error rate is too high — it measures the physical state of the channel continuously, proves entanglement is intact, identifies what degraded it and when, and red-teams itself with quantum attacks.

**No AI, no machine learning.** The PS excludes them. Every decision is a statistical hypothesis test or a physical measurement.

### What every other submission will be

Bell pairs → teleportation → sign → verify → a chart of forgery probability falling with key length, and an acceptance threshold hardcoded at 0.15. Correct, complete, and identical across forty submissions.

### The gap we exploit

Every QDS implementation accepts a signature when the mismatch rate falls below a threshold. Real channels are noisy, so legitimate signatures also produce mismatches.

> **A verifier sees a 9% mismatch rate. Is that a degraded fibre, or an attacker?** Nobody answers this. They compare 9 to 15 and move on.

### Our six instruments

| | Instrument | What it proves |
|---|---|---|
| **I1** | **CHSH entanglement monitor** | Live physical proof no eavesdropper is present. A theorem, not a heuristic. |
| **I2** | **Pauli-basis fingerprinting** | Which cause produced the errors — noise is isotropic, attacks are basis-selective |
| **I3** | **Process tomography** | The channel's complete physical operator: fidelity, unitarity, non-unitality |
| **I4** | **Statistical stack** | Bayesian posterior, SPRT, CUSUM change-point, finite-key bounds |
| **I5** | **Quantum red-teaming** | Grover forgery search and Quantum Amplitude Estimation — we attack ourselves |
| **I6** | **Independent channels** | Decoy states and timing side-channel — orthogonal detection axes |

**The one-liner:** *Everyone checks whether the error rate is too high. We run a live instrument on the channel — proving entanglement is intact, identifying what degraded it and when, and attacking ourselves with Grover to prove the signature still holds.*

## 2. Non-negotiable rules

### 2.1 No AI, no ML — the PS says so explicitly
No neural networks, classifiers, clustering, or "anomaly detection models". χ², Bayesian inference, SPRT, CUSUM and Hoeffding bounds are classical statistics, not machine learning. **If you import `sklearn` or `torch`, stop.**

### 2.2 Every number is measured, never asserted
Reference profiles, detection rates, CHSH values, rounds-to-decision — all from seeded simulation runs, all reproducible from one command. **Do not hardcode analytic values as results.** Every figure must trace to a run whose seed is recorded.

This applies with special force to the website. **A number on the site that did not come from a real Qiskit run is the one thing that can end this submission.**

### 2.3 State what the method cannot do
The fingerprint separates basis-selective from isotropic effects cleanly. It does not separate every pair:

- Phase damping and weak Z-intercept share the shape `[e, e, 0]` — magnitude separates them, shape does not
- Blind forgery and severe depolarising are both isotropic near 0.5

**Report attribution with a runner-up hypothesis and an `INCONCLUSIVE` verdict when the top two are not separated.** A framework that names its blind spots is more credible than one that always decides.

### 2.4 Honest security claims
Information-theoretic security holds **under stated assumptions**: trusted measurement devices, authenticated classical channel, and the specific attack model implemented. Never claim the framework detects "all attacks" — it detects the implemented suite, at the sensitivities measured.

### 2.5 CHSH is a physical bound, respect it
`S ≤ 2√2 ≈ 2.828` is Tsirelson's bound. **A simulation reporting S > 2.828 is a bug, not a discovery.** Assert it.

### 2.6 Reproducibility
Every run seeded. Every figure regenerated by `python -m experiments.run_all`. A judge who cannot reproduce one number will not trust the rest.

## 6. Release gates

Six tests. Do not present without them green.

- `test_protocol.py` — honest signature accepted **100%** on a noiseless channel, 500 seeded runs
- `test_chsh.py` — noiseless Bell pairs give **S ≈ 2.828 ± tolerance**, and **S never exceeds 2√2**
- `test_fingerprint.py` — Z-intercept never attributed as depolarising at strength ≥ 0.3, and vice versa
- `test_thresholds.py` — derived `s_a` hits the target false-rejection rate on **held-out** runs
- `test_replay.py` — replayed signature rejected **100%**, deterministically
- `test_reproduce.py` — `run_all` twice with the same seed produces identical results
